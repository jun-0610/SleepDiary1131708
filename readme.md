# Sleep Quality Diary 睡眠品質日記系統

## 專案簡介

Sleep Quality Diary 是一套以 ASP.NET Core MVC 開發的睡眠紀錄管理系統，讓使用者能夠記錄每日睡眠狀況、查詢歷史資料，並透過系統管理個人睡眠品質。

本專案為大學課程專題作品，實作過程中完整運用了前後端開發、資料庫設計及 MVC 架構概念。

---

## 系統功能

### 使用者功能
- 使用者註冊與登入
- 睡眠紀錄新增、修改與刪除
- 睡眠資料查詢
- 個人睡眠品質管理

### 系統功能
- 帳號驗證
- 資料庫 CRUD 操作
- MVC 架構分層開發
- 響應式網頁介面設計

## 開發過程中的挑戰

在開發過程中，最常遇到的問題是資料庫操作與前後端資料傳遞錯誤。當功能無法正常執行時，需要透過除錯工具、查閱技術文件與測試不同解法逐步找出問題原因。

透過不斷修正與測試，我對 MVC 架構、資料庫操作以及系統開發流程有更深入的理解，也培養了解決問題與自主學習能力。
